# Composition search

## Observation bell
The **Observation bell** filter restricts the search to compositions with a particular [observation bell](../compositions/adding_compositions_tabs_general.md/#observation-bell):

Any
:   Compositions are included whatever their observation bell. This is the default.

None
:   Only compositions with no observation bell, e.g. those which only use numbered calling positions, or which have no calls.

Tenor
:   Only compositions whose observation bell is the tenor.

Not tenor
:   Only compositions whose observation bell is a bell other than the tenor.

A specific bell
:   Once a stage has been selected, the individual bells of that stage are also listed, so you can search for compositions using a particular observation bell, e.g. the 2nd.
